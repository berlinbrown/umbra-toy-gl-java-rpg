# Umbra Dark

A small, pure Java/LibGDX dark-fantasy RPG vertical slice.

## Play

- `W/S` move forward/backward; `A/D` turn.
- Left-click the ground to walk to the highlighted destination.
- Approaching the Hollow Guard pauses the world and opens **Attack / Flee**.
- Attack starts automatic RPG combat. `R` restarts after defeat; `Esc` quits.

The first area is isolated in `DarkCourtyardScene`, making it straightforward to add another scene with the same create/update/render-data lifecycle.

## Basic Libgdx Examples

Show various OpenGL and libgdx examples, camera movement, etc
